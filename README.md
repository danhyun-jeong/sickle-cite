# 최근 주요 업데이트 내용

## 2.0.0 버전 메이저 업데이트 사항

1. **신기능**
	1. **인용 형식 조합**: [<img src="docs/icons/settings.svg" width="16" height="16" align="absmiddle" alt=""> 설정] 탭의 인용 형식 세부 설정들의 조합에 이름을 붙여 최대 10개까지 저장해 두고, 원할 때 일괄 적용할 수 있습니다. 저장된 조합은 [<img src="docs/icons/current-page.svg" width="16" height="16" align="absmiddle" alt=""> 현재 페이지 서지정보] 탭에서도 바로 바꿀 수 있습니다. 처음에는 기본 설정으로 된 ‘Sickle-Cite 기본’ 조합이 있습니다. (자세한 내용은 [여기](#인용-형식-세부-설정)를 참고)
	2. **내역 검색 강화**: [<img src="docs/icons/history.svg" width="16" height="16" align="absmiddle" alt=""> 서지정보 추출 내역]의 검색 창 왼쪽에서 검색할 항목(전체/저자/제목/학술지명/발간기관/키워드/초록/태그)을 고를 수 있습니다. 검색 창 아래의 필터로 자료 유형(학술지논문/학위논문)과 발행 연도 범위에 따라 내역을 거를 수도 있습니다. 검색 창 안에는 저장된 논문 편수가, 검색 중에는 해당하는 편수도 함께 표시됩니다.
	3. **내역 백업 및 가져오기**: [<img src="docs/icons/settings.svg" width="16" height="16" align="absmiddle" alt=""> 설정] 탭에서 서지정보 추출 내역 전체를 JSON 파일로 내보내 백업해 둘 수 있습니다. 백업해 둔 파일을 가져와 기존 내역과 합치거나 전체를 교체할 수 있으므로, 내역을 특정 시점으로 되돌리거나 다른 컴퓨터로 옮길 때 쓸 수 있습니다.
	4. **서지정보 직접 입력 저장**: 지원하지 않는 페이지에서도 서지정보를 직접 입력해 내역에 저장할 수 있습니다. 직접 입력한 항목은 [<img src="docs/icons/history.svg" width="16" height="16" align="absmiddle" alt=""> 서지정보 추출 내역]의 학술 DB 칸에 ‘직접 입력’으로 표시됩니다. 저장할 때 필수 항목과 숫자 값(권수·호수·쪽 범위·연도)을 검사하고, 학위논문의 발간기관 표기를 ‘○○대학교 ○○학과 석사학위논문’ 형식으로 통일합니다. (자세한 내용은 [여기](#탭-1-현재-페이지-서지정보)를 참고)
	5. **동일 논문 저장 방식 설정**: 같은 논문을 다시 추출할 때 매번 내역에 저장할지, 첫 번째 추출만 저장할지 고를 수 있습니다. 첫 번째 추출만 저장하기로 하면, 이미 쌓인 중복 항목을 한꺼번에 정리하는 [기존 중복 항목 삭제] 버튼이 나타납니다.
	6. **인용 표기 옵션 추가**: 권수 앞의 ‘제’와 호수 앞의 ‘제’를 각각 붙이거나 뺄 수 있게 되었습니다. 또한 전각 홑낫표(「 」) 대신 반각 홑낫표(｢ ｣)를 쓰는 옵션이 생겼습니다. ‘인용 표기에 쪽 범위 포함하기’는 이제 켜져 있는 것이 기본입니다.
	7. **테마 설정**: 밝은 테마, 어두운 테마, 자동(운영체제의 밝은·어두운 모드를 따름) 중에서 고를 수 있습니다.
2. **추출 정확도 개선**
	- 서지정보를 추출할 때 페이지의 메타데이터와 화면에 표시된 정보를 서로 대조해 교차 검증하고, 둘이 다르면 더 온전한 쪽을 택하도록 알고리즘을 개선했습니다. 이에 맞추어 각 학술 DB별 추출 방식도 다시 최적화했습니다.
3. **같은 논문 판별 개선**
	- 같은 논문인지 판단하는 기준을 더 정확하게 바꾸었습니다. (자세한 기준은 [여기](#하단-버튼-및-스위치)를 참고)
	- 서지정보를 직접 수정해 저장하면, 같은 논문으로 묶인 모든 내역에 수정 사항이 함께 반영됩니다. 수정한 결과 다른 묶음과 같은 논문이 되면 두 묶음을 합치고, 양쪽의 태그도 모읍니다.
	- 업데이트하면 기존 내역도 새 기준에 따라 자동으로 다시 묶입니다.
4. **내역 저장 용량 제한 해제**
	- 내역 저장 용량 제한을 없앴습니다. 대신 저장된 데이터가 10MB를 넘으면 팝업을 열 때 안내합니다.
5. **지원되는 DB 추가**
	- **연세대학교 도서관 웹사이트**의 상세 페이지에서도 서지정보를 추출할 수 있습니다. 소장자료 상세 페이지와 학술논문 검색(EDS) 상세 페이지(로그인 필요)를 모두 지원합니다. 다만 도서관 웹사이트의 페이지에는 원래 학술 DB 페이지보다 서지정보가 불충분하거나 불규칙하게 등록되어 있는 경우가 많아 추출 시 누락이 일어날 수 있으므로, 되도록 원래 학술 DB 페이지에서 추출하시기를 권합니다.
6. **UI/UX 개선**
	- 팝업 디자인 전반을 손질하고(카드·입력칸·버튼 모양 통일, 단색 선 아이콘 사용 등), 일부 항목의 명칭을 정리했습니다(‘조합된 인용 표기’ → ‘인용 표기’, ‘프로젝트 태그 추가’ → ‘태그 추가’).

## 1.7.0 버전 메이저 업데이트 사항

1. **신기능**: 내역(히스토리) 기능이 대폭 강화되어 사용자의 서지 관리를 더 용이하게 해줍니다.
	- [<img src="docs/icons/history.svg" width="16" height="16" align="absmiddle" alt=""> 서지정보 추출 내역] 탭의 표의 각 행 맨 앞(왼쪽)에 추가된 체크박스를 통해 여러 항목(전체 또는 선택된 일부)을 한번에 제어할 수 있게 되었습니다.
	1. **참고문헌 목록 자동 생성하여 간편하게 복붙 가능**: 이제 더 이상 추출한 각 논문의 인용 표기를 일일히 클립보드에 복사할 필요가 없고, 체크박스에 체크된 항목(논문)에 해당하는 인용 표기 전체를 한꺼번에 클립보드에 복사할 수 있게 되었습니다.
	2. **서지관리 프로그램과의 호환성 추가**: 체크박스에 체크된 항목(논문)에 대한 모든 정보(서지정보, 추출한 DB, URL, 추출 일시, 인용 표기, 태그)를 엑셀 파일 형태 또는 RIS 파일 형태로 내보내기(export) → 다운로드할 수 있습니다.
		- 특히, 새롭게 RIS 파일(.ris 확장자)로 내보내기 → 다운로드가 가능해졌습니다. RIS는 서지정보를 기록하는 파일 형식으로, 여러 서지관리 프로그램(Endnote, Mendeley, Zotero, Citeasy 등)에서 지원하는 범용 포맷입니다. 즉, 이제 Sickle-Cite로 추출한 서지정보를 한번에 내보내기한 후 설치된 서지관리 프로그램에서 가져오기(import)할 수 있습니다.
2. **UI/UX 개선**
	1. **내역에서의 항목 삭제 방식 변경**: 신기능 추가와 발맞추어, 내역 전체 또는 일부 항목을 삭제하는 방식이 바뀌었습니다.
		- 내역 표의 각 행 맨 오른쪽에 있던 삭제 버튼이 사라지고, 맨 왼쪽에 체크박스가 생겼습니다.
		- 최소 한 개 이상의 체크박스에 체크가 되면 팝업 창 하단에 [삭제] 버튼이 나타나며, 이를 통해 내역 전체 또는 일부 항목을 삭제할 수 있습니다.
	2. **내역 표 더 널찍하게 보기**: "[학술 DB], [추출 일시] 열 숨기기" 토글 스위치가 추가되어, [논문 제목] 열을 넓혀서 볼 수 있습니다.
		- 추가된 "[학술 DB], [추출 일시] 열 숨기기" 토글 스위치를 on 하면, 말 그대로 [학술 DB] 열과 [추출 일시] 열이 숨겨지면서 논문 제목 정보를 더 많이 보여주게 됩니다. 특히, 이때 논문의 부제목까지 포함한 전체 제목이 표시됩니다.

# 0. 설치 방법

## 가장 쉬운 설치 방법 — 크롬 웹 스토어를 통해 크롬에 바로 설치하기

2.0.0 버전을 크롬 웹 스토어를 통해 브라우저에 바로 설치할 수 있습니다: [크롬 웹 스토어 링크](https://chromewebstore.google.com/detail/sickle-cite-beta/gcpfjpjfdocpojlfboppejoommfmhdlp)

신버전이 나올 때마다 크롬 웹 스토어에도 게시할 예정이나, 구글 크롬 측에서 제출된 확장 프로그램을 검토한 후에 승인하기까지 시일이 소요되므로, 새로운 버전이 나올 때마다 빠르게 팔로업하실 분들은 지금 보시는 이 Github 리포지토리를 즐겨찾기에 등록해주시면 됩니다.

## 여기(Github)에서 .zip 파일을 다운받은 뒤 크롬에 설치하는 방법

여기에서는 2.0.0 버전의 패키지를 zip 파일 형태로 다운로드하여 설치할 수 있습니다.

오른쪽 **Releases**에서 최신 버전의 zip파일(맨 위의 파일) 다운로드 ⇒ 압축 해제한 폴더를 원하는 아무 적당한 위치로 옮기기(이후 이 폴더 위치를 변경할 경우 확장 프로그램이 작동하기 않게 됩니다. 처음부터 추후 변경할 일이 없을 위치에 두시는 것을 권합니다) ⇒ 크롬에서 오른쪽 위의 ⠇ → 확장 프로그램 → 확장 프로그램 관리 → 오른쪽 위의 ‘개발자 모드’ on → 왼쪽 위의 ‘압축해제된 확장 프로그램을 로드합니다.’ → 압축 해제한 폴더를 ‘열기’

# 1. 들어가며

한국의 국문학계를 위시한 인문학 분야에서는 인용 표기에 낫표(『 』, 「 」)를 사용하여 제목을 표기하는 등의 이른바 관습적인 ‘독자 양식’을 사용하고 있습니다. 기존의 서지 관리 프로그램이나 인용 표기 생성기(citation generator)에서는 이러한 양식을 지원하지 않았으므로, 지금껏 국내 인문학 분야에서는 그런 유용한 프로그램을 이용하기 어려웠습니다. 이러한 문제를 해결하고자, 국내 인문학 분야의 인용 관습 실정에 맞는 크롬 확장 프로그램을 개발했습니다. 단순한 인용 표기 생성기에서 그치지 않고, 서지 관리 프로그램의 필수 기능까지 담아내면서도 너무 무겁거나 복잡하지 않도록 균형을 잡았습니다.

# 2. 사용법 및 기능

본 확장 프로그램은 아래의 설명을 읽지 않아도 별 문제가 없을 만큼 누구나 직관적이고 쉽게 사용가능합니다. 그럼에도 확장 프로그램의 기능을 자세하게 알아보고 싶으신 분을 위해 사용법과 기능 설명을 적어둡니다.

## (1) 핵심 기능 및 사용법

- 학술 데이터베이스의 논문 검색 결과 페이지에서 확장 프로그램을 실행(아이콘 클릭)하여 팝업 창을 열기만 하면, 그 즉시 해당 페이지에서 ‘<img src="docs/icons/metadata.svg" width="16" height="16" align="absmiddle" alt=""> 논문의 서지정보’를 추출하여 결과물을 보여줍니다.
	- 추출하는 서지정보 항목은 다음과 같습니다: 저자, 본제목, 부제목, 학술지명, 권수, 호수, 발간기관, 연도, 첫 페이지, 끝 페이지, 키워드, 국문 초록
- 서지정보를 조합하여 ‘<img src="docs/icons/citation.svg" width="16" height="16" align="absmiddle" alt=""> 인용 표기’로 만들어서 보여주며, 버튼 하나로 이를 간편하게 클립보드에 복사할 수 있습니다.
- 추출된 결과 중 수정하고 싶은 사항이 있을 경우, 복사하기 전에 사용자가 직접 수정할 수 있습니다. 수정 사항을 저장할 수도 있습니다.
- 추출한 논문 서지정보에 더해, 사용자가 직접 태그를 달아 논문을 분류할 수 있습니다.
- 추출된 서지정보는 자동으로 ‘<img src="docs/icons/history.svg" width="16" height="16" align="absmiddle" alt=""> 내역(히스토리)’에 저장됩니다. 이렇게 저장된 서지정보는(태그 포함) 검색 가능합니다.
	- (2.0.0 버전 신기능) 검색할 항목을 골라 검색할 수 있고, 자료 유형과 발행 연도 범위로 내역을 거를 수 있습니다.
- (1.7.0 버전 신기능) 내역에서 전체 또는 일부 항목을 선택하여 (1) 인용 표기를 모아 한꺼번에(즉 참고문헌 목록으로 만들어) 클립보드에 복사할 수 있으며, (2) 서지정보(+⍺)를 엑셀 파일 또는 .ris 파일 형태로 내보내기 → 다운로드할 수 있습니다.
- (1.7.0 버전 신기능) Sickle-Cite로 추출한 서지정보를 Endnote, Mendeley, Zotero, Citeasy 등 서지관리 프로그램으로 손쉽게 내보내기-가져오기 할 수 있습니다.
- (2.0.0 버전 신기능) 서지정보 추출 내역 전체를 JSON 파일로 백업해 두고, 언제든 다시 가져올 수 있습니다.
- [<img src="docs/icons/settings.svg" width="16" height="16" align="absmiddle" alt=""> 설정] 탭에서 인용 표기 양식을 수정할 수 있는 몇 가지 옵션을 제공합니다. 테마(밝은/어두운/자동) 등 프로그램 설정도 바꿀 수 있습니다.

참고로, 서지정보를 가져올 때 **각종 기호 사용이 ‘원칙에 어긋난’ 것이 있으면 자동으로 ‘표준적인’ 기호로 바꾸어 통일합니다.**

### 탭 1. 현재 페이지 서지정보

<p align="center"><img width="650" alt="Image" src="https://github.com/user-attachments/assets/d3b53432-cab3-4c3d-9e94-33e47f6d34ec" /></p>

- [<img src="docs/icons/current-page.svg" width="16" height="16" align="absmiddle" alt=""> 현재 페이지 서지정보] 탭이 눌려 있을 때 표시되는 화면의 좌측 〈<img src="docs/icons/metadata.svg" width="16" height="16" align="absmiddle" alt=""> 논문 서지정보〉 부분에서는 논문의 서지정보(metadata)를 항목별로 볼 수 있으며, 우측 상단 〈<img src="docs/icons/citation.svg" width="16" height="16" align="absmiddle" alt=""> 인용 표기〉 부분에서는 서지정보를 바탕으로 인용 표기(citation)를 확인할 수 있습니다.
- 본 확장 프로그램을 실행하면, 즉 팝업 창을 열면 그것이 트리거가 되어 현재 페이지에서 논문의 서지정보를 추출하여 〈<img src="docs/icons/metadata.svg" width="16" height="16" align="absmiddle" alt=""> 논문 서지정보〉의 각 필드와 〈<img src="docs/icons/citation.svg" width="16" height="16" align="absmiddle" alt=""> 인용 표기〉의 필드를 채웁니다. 즉 ‘서지정보 추출하기’ 버튼 같은 것은 없습니다. 그냥 이 확장 프로그램을 실행하면 = 팝업 창을 열기만 하면 됩니다.
- **모든 텍스트는 복사에 앞서 사용자가 직접 수정할 수 있습니다.** 서지정보를 수정하면, 그 사항은 실시간으로 우측의 〈<img src="docs/icons/citation.svg" width="16" height="16" align="absmiddle" alt=""> 인용 표기〉 필드에 표시된 결과물에 반영됩니다. (다만 〈<img src="docs/icons/citation.svg" width="16" height="16" align="absmiddle" alt=""> 인용 표기〉에서의 수정 사항은 〈<img src="docs/icons/metadata.svg" width="16" height="16" align="absmiddle" alt=""> 논문 서지정보〉에 반영되지 않습니다.)
- 국문 초록이 길면 몇 줄만 접어서 보여줍니다. 초록 아래 오른쪽의 [더 보기]를 누르면(또는 초록을 클릭하면) 전체가 펼쳐지고, [접기]를 누르면 다시 접힙니다.
- 서지정보를 일부 수정한 뒤에 그 결과물을 내역(history)에 저장하고 싶을 경우, [수정사항을 내역에 저장] 버튼을 누르면 됩니다.
	- 서지정보 추출 후 직접 수정 사항이 없을 때는 이 버튼을 누르지 않아도 됩니다. 추출이 되자마자 추출된 결과물은 자동적으로 내역에 저장되기 때문입니다.
	- 수정 사항은 같은 논문으로 묶인 모든 내역에 함께 반영됩니다. 수정한 결과 내역의 다른 논문 묶음과 같은 논문이 되면, 두 묶음을 하나로 합치고 양쪽의 태그를 모읍니다(최대 10개).
- 같은 논문의 서지정보를 이전에 추출한 적이 있으면, 그 사실을 알려주면서 최초로 추출된(사용자가 수정해 저장했다면 수정된) 서지정보를 불러옵니다.
- **서지정보를 직접 입력해 저장할 수도 있습니다.** 지원하지 않는 페이지에서 실행해 서지정보 입력란이 비어 있을 때, 각 입력란에 직접 서지정보를 입력한 뒤 [수정사항을 내역에 저장] 버튼을 누르면 내역에 새 항목으로 추가됩니다. 이후 다시 누르면 그 항목에 수정 사항이 반영됩니다.
	- 직접 입력한 항목은 [<img src="docs/icons/history.svg" width="16" height="16" align="absmiddle" alt=""> 서지정보 추출 내역]의 학술 DB 칸에 ‘직접 입력’으로 표시되며, 원래 페이지가 없으므로 링크는 없습니다.
	- 저자, 본제목, 학술지명, 발간기관, 쪽 범위, 연도는 반드시 입력해야 합니다. 단, 학위논문의 경우에는 발간기관에 ‘학위논문’ 표현이 있으면 학술지명과 쪽 범위를 입력하지 않아도 됩니다.
	- 권수, 호수, 쪽 범위, 연도에는 숫자만 입력할 수 있습니다. (연도는 네 자리)
	- 학위논문의 발간기관은 저장할 때 ‘○○대학교 ○○학과 석사학위논문’ 형식으로 띄어쓰기가 통일됩니다. (예: ‘연세대학교 석사 학위 논문’ → ‘연세대학교 석사학위논문’)
	- 이미 내역에 있는 논문과 같은 논문으로 판별되면, 그 사실을 알려주고 함께 묶습니다. 설정에서 같은 논문은 첫 번째만 저장하도록 했다면, 새로 추가하지 않고 저장되어 있던 항목을 불러옵니다.
- 논문의 각 항목별 서지정보, 그리고 최종적으로 인용 표기는 각각 [텍스트로 복사], [<img src="docs/icons/copy.svg" width="16" height="16" align="absmiddle" alt=""> 클립보드에 복사] 버튼을 눌러 클립보드에 복사할 수 있습니다. (드래그한 다음에 Ctrl+C 누르실 필요 없다는 뜻입니다.)
- (신버전 기능) 추출한 논문 서지정보에 더해, 사용자가 직접 ‘<img src="docs/icons/tag.svg" width="16" height="16" align="absmiddle" alt=""> 태그’를 달 수 있습니다.
	- 공부·연구를 하다보면 동시에 여러 가지 연구를 진행하게 되는 경우가 많죠? 그러다보니 [<img src="docs/icons/history.svg" width="16" height="16" align="absmiddle" alt=""> 서지정보 추출 내역]에도 각기 다른 이유와 목적으로 찾아본 논문들이 한데 뒤섞여 있곤 했습니다. 이제 이를 분류, 필터링할 수 있습니다.
	- 〈<img src="docs/icons/tag.svg" width="16" height="16" align="absmiddle" alt=""> 태그 추가〉 입력창에 텍스트를 입력하고 Enter 키를 누르면 칩 형태의 UI가 적용되면서 태그가 추가됩니다. 입력창이 비어 있을 때 Backspace 키를 누르거나 각 태그 칩의 오른쪽에 있는 삭제 버튼(×)을 클릭해 삭제할 수 있습니다.
	- 태그를 추가하거나 삭제할 때 자동으로 내역(히스토리)에도 저장되며, [<img src="docs/icons/history.svg" width="16" height="16" align="absmiddle" alt=""> 서지정보 추출 내역]에서 이를 확인할 수 있습니다. (자세한 내용은 다음 절에서)
	- 전에 추가된 바 있는 태그와 부분 일치하는 문자열을 입력할 경우, 최대 4개까지 자동완성(추천) 리스트가 뜨게 됩니다. 항목을 클릭하거나, 상하 방향키 + Enter 키로 선택하여 입력할 수 있습니다. Tab 키를 누를 경우 가장 첫 번째 항목이 입력됩니다.
	- 각각의 태그는 공백 포함 최대 15자까지 가능하며, 하나의 논문에 최대 10개까지의 태그를 달 수 있습니다.

### 탭 2. 서지정보 추출 내역

<p align="center"><img width="650" alt="Image" src="https://github.com/user-attachments/assets/fbb2c6f1-43b3-4111-af8f-077f802b1e0a" /></p>

- [<img src="docs/icons/history.svg" width="16" height="16" align="absmiddle" alt=""> 서지정보 추출 내역]은 영어로는 ‘history’라 불리는 것입니다. 지금까지 본 확장 프로그램을 실행함으로써 추출한 서지정보는 팝업 창이 닫혔을 때 사라지는 것이 아니라 이곳에 저장됩니다. 그렇기에 [탭 1]에서 매번 미리 복사해놓고 다른 어딘가에 붙여넣기 해두고…… 하실 필요 없습니다. 서지정보 추출이 잘 되었는지만 눈으로 확인하신 후에는, 안심하고 그저 팝업 창 닫고 하시던 작업을 마저 하시면 됩니다. 한번 추출된 논문 서지정보는 그 정보를 어디서, 언제 추출했는지에 관한 정보와 함께, 언제든 나중에 다시 확인할 수 있습니다. 단, **이 확장 프로그램을 삭제하실 경우 저장되어 있던 내역도 삭제됩니다.**

#### 내역 표

1. ‘저자’
	- 저자가 여러 명이면 첫 번째 저자만 표시하고 ‘외’를 붙입니다. 이 경우, 마우스 커서를 갖다대고 잠시 기다리면 툴팁 창을 통해 전체 저자 목록을 확인할 수 있습니다.
2. ‘논문 제목’
	- 기본적으로 부제목을 뺀 본제목만을 보여줍니다.
	- 본제목이 길 경우 뒷부분을 생략하고 ‘…’를 붙입니다. 마찬가지로, 마우스 커서를 갖다대고 잠시 기다리면 툴팁 창을 통해 부제목을 포함한 전체 제목을 확인할 수 있습니다.
3. ‘태그’
	- 사용자가 직접 입력해 추가해둔 태그를 볼 수 있습니다.
	- 표에서는 첫 번째 태그만 보여집니다. 태그가 여러 개일 경우, ‘n개의 태그가 더 있다’는 의미로 ‘+n’ 배지가 태그의 우상단에 나타납니다. 마우스 커서를 갖다대고 잠시 기다리면 툴팁 창을 통해 모든 태그를 확인할 수 있습니다.
	- 태그가 8글자(공백 포함) 이상으로 길 경우 뒷부분이 생략되고 ‘…’이 붙습니다.
	- 표의 각 행에서 ‘저자’, ‘논문 제목’, ‘태그’ 열에 해당하는 부분을 클릭하면 [탭 1]로 넘어가지고, 클릭한 논문의 서지정보 및 완성된 인용 표기를 띄워줍니다. 즉 이런 식으로 각 행(논문)의 상세 정보를 다시 확인할 수 있습니다.
4. ‘학술 DB’
	- ‘학술 DB’ 열을 클릭하면, 해당 논문의 서지정보를 추출했었던 바로 그 웹페이지로 접속합니다. (단, 대학 도서관을 통해 인증하여 학술 데이터베이스에 접속한 경우, 인증이 만료되면 해당 링크로 접속이 어려울 수 있습니다. 이 경우 대학 도서관 홈페이지에서 로그인하여 인증한 뒤 다시 클릭하면 정상적으로 접속됩니다.)
5. ‘추출 일시’
	- 논문의 서지정보를 추출한 연, 월, 일, 시, 분을 표시합니다. (표에서는 분 단위까지 나오지만 실제로는 초 단위까지 정보를 수집합니다.)

- 내역이 많을 경우, 표에는 최근 500개만 먼저 표시됩니다. 표 맨 아래의 [내역 더 보기] 버튼으로 500개씩 더 불러오거나, [내역 전체 불러오기] 버튼으로 남은 내역을 모두 불러올 수 있습니다.

#### 검색 창

- 검색 창에서는 말 그대로 검색을 하실 수 있습니다. 이때 현재 [탭 2] 화면에서 보이는 정보, 즉 ‘저자’와 ‘제목’만 검색 가능한 것이 아니고, 논문의 서지정보에 해당하는 모든 정보가 다 검색됩니다. 예컨대 학술지명을 검색하면 해당 학술지에 게재된 논문만 모아 볼 수 있습니다. 키워드나 국문 초록 정보가 있을 경우 이 역시 검색에 걸리게 됩니다.
- (2.0.0 버전 신기능) 검색 창 안 왼쪽의 드롭다운 버튼에서 검색할 항목을 고를 수 있습니다: 전체, 저자, 제목, 학술지명, 발간기관, 키워드, 초록, 태그. 예컨대 ‘저자’를 고르고 검색하면, 저자 이름에 검색어가 들어 있는 논문만 찾습니다. (‘전체’에서는 초록에 그 이름이 언급된 논문까지 검색에 걸립니다.)
- 공백으로 나누어 여러 단어를 입력하면, 그 단어가 모두 들어 있는 논문만 찾습니다.
- 검색 창 안 오른쪽에는 저장된 논문의 편수(총 ○○편)가 표시되며, 검색 중일 때는 그중 검색 결과에 해당하는 편수(○○편 / 총 ○○편)도 함께 표시됩니다.
- 한글의 초성+중성+종성 조합 구조를 고려한 fuzzy 검색을 지원합니다. 그렇기에, 예컨대 ‘국ㅁ’까지만 쳤을 때에도 ‘국민국가’를 검색해낼 수 있고 ‘굯’까지만 쳤을 때에도 ‘국수주의’를 검색해낼 수 있습니다.
- 태그 역시 검색이 됩니다. 태그로 검색하면 해당 태그가 달려 있는 논문을 한 데 모아 볼 수 있습니다.

#### 필터

- (2.0.0 버전 신기능) 검색 창 아래의 필터로 내역을 거를 수 있습니다. 검색과 함께 쓸 수도 있습니다.
	- ‘유형’: [전체] 또는 [학술지논문], [학위논문] 중 하나를 고르면 해당 유형의 논문만 보여줍니다.
	- ‘연도’: 발행 연도의 범위를 정해 그 범위의 논문만 보여줍니다. 시작 연도와 끝 연도 중 하나만 입력해도 됩니다. (네 자리를 다 입력해야 적용됩니다.)
- 필터를 적용 중일 때는 오른쪽에 [↺ 필터 초기화] 버튼이 나타나며, 이를 누르면 필터가 모두 해제됩니다.

1. 팝업 창의 맨 아래 오른쪽에는 "같은 논문이 중복될 경우 첫 번째만 표시" 토글 스위치와 "[학술 DB], [추출 일시] 열 숨기기" 토글 스위치가 있습니다.
	1. "같은 논문이 중복될 경우 첫 번째만 표시" 토글 스위치
		- 토글 스위치가 on 되어있을 경우(기본으로 on 되어 있습니다), 같은 논문을 여러 번 검색, 추출했어도 그 중 맨 이른 시간의 것 하나만 보여줍니다. 토글 스위치를 off 하시면, 모든 추출 내역이 중복 포함해서 다 표시됩니다. 이때 ‘같은 논문’은 다음과 같이 판단합니다. ① 추출한 URL이 가리키는 논문 고유번호(DBpia의 `nodeId`, RISS의 `control_no`, 연세대 도서관의 자료번호 등)가 같으면 무조건 같은 논문입니다. 대학 도서관 프록시를 거쳐 접속한 경우에도 마찬가지입니다. ② 그렇지 않으면 서지정보를 비교해, 저자가 한 명 이상 겹치고, 본제목·부제목을 합친 전체 제목과 학술지명이 같으면 같은 논문으로 봅니다. 이때 띄어쓰기·문장부호·대소문자 차이는 무시하고, 한두 글자의 오타·오기는 허용합니다. 이 판단은 내역에 처음 추가될 때 한 번만 이루어지므로, 이후 서지정보를 고쳐 저장해도 같은 논문으로 계속 묶입니다.
		- 이 토글 스위치는 [<img src="docs/icons/copy.svg" width="16" height="16" align="absmiddle" alt=""> 인용 표기 복사] 버튼 및 [서지정보 내보내기] 버튼 클릭 시의 작동 결과에도 영향을 미칩니다.
	2. "[학술 DB], [추출 일시] 열 숨기기" 토글 스위치
		- 이 토글 스위치를 on 하면, 말 그대로 [학술 DB] 열과 [추출 일시] 열이 숨겨지면서 논문 제목 정보를 더 많이 보여주게 됩니다. 특히, 이때 논문의 부제목까지 포함한 전체 제목이 표시됩니다.
		- "같은 논문이 중복될 경우 첫 번째만 표시" 토글 스위치가 off 되어 있으면서 동시에 "[학술 DB], [추출 일시] 열 숨기기" 토글 스위치가 on 되어 있을 수는 없도록 작동합니다.
2. 내역 표의 각 행 맨 앞(왼쪽)에 있는 체크박스 중 최소 하나 이상의 체크박스에 체크가 될 경우, 맨 아래 왼쪽에 차례대로 [삭제], [<img src="docs/icons/copy.svg" width="16" height="16" align="absmiddle" alt=""> 인용 표기 복사], [서지정보 내보내기] 버튼이 나타납니다.
	1. [삭제] 버튼
		- 체크되어 있는 항목들을 내역에서 영구히 삭제합니다. 클릭했을 때 바로 삭제가 실행되지는 않고, 정말 삭제할 것인지를 재차 물어보는 창이 뜹니다.
		- 삭제된 항목은 복원이 불가능합니다.
		- 사용자가 삭제를 누르지 않는 한, 기본적으로 내역은 계속해서 쌓입니다. (2.0.0 버전부터 저장 용량 제한이 없어졌습니다. 다만 저장된 데이터가 10MB를 넘으면 프로그램 실행이 느려질 수 있으므로, 팝업을 열 때 이를 안내합니다.) 확장 프로그램을 삭제할 경우 이 내역도 같이 삭제됩니다. 오류 또는 실수 등으로 서지정보 내역이 손실될까봐 걱정되실 경우에는, [<img src="docs/icons/settings.svg" width="16" height="16" align="absmiddle" alt=""> 설정] 탭에서 내역 전체를 JSON 파일로 내보내 백업해두시는 것을 권해드립니다. (아래 [탭 3. 설정](#탭-3-설정) 참고)
	2. [<img src="docs/icons/copy.svg" width="16" height="16" align="absmiddle" alt=""> 인용 표기 복사] 버튼
		- 체크되어 있는 항목(논문)의 인용 표기를 줄바꿈 적용하여 연결한 문자열(텍스트) 전체를 클립보드에 복사합니다. 버튼을 클릭하면 현재 설정된 양식을 확인할 수 있는 창을 띄우고, 여기서 다시 [<img src="docs/icons/copy.svg" width="16" height="16" align="absmiddle" alt=""> 클립보드에 복사] 버튼을 누르면 복사됩니다. 한글이나 워드 등 원하는 곳에서 붙여넣기하면 참고문헌 목록을 순식간에 완성할 수 있습니다.
		- 이때 적용되는 인용 표기는 탭 1에서 확인할 수 있는 인용 표기와 같은 양식이며, [<img src="docs/icons/settings.svg" width="16" height="16" align="absmiddle" alt=""> 설정] 탭에서 양식을 변경할 수 있습니다.
		- 기본적으로 저자 이름 오름차순으로 정렬됩니다. 저자 이름이 같을 경우 연도 오름차순으로 정렬됩니다.
	3. [서지정보 내보내기 버튼]
		- 체크박스에 체크된 항목에 해당되는 정보(서지정보, 추출한 DB, URL, 추출 일시, 인용 표기, 태그) 일체를 내보내기 합니다. 엑셀 파일 또는 RIS 파일 형태로 내보내기(export) → 다운로드할 수 있습니다.
		- 내역을 엑셀 파일로 저장하는 기능은 이전 버전에도 있었으나 항상 전체 내역을 다운로드하게 되어 있었습니다. 이제 일부 항목만 선택하여 엑셀 파일로 저장할 수 있습니다.
		- RIS는 서지정보를 기록하는 파일 형식으로, 여러 서지관리 프로그램(Endnote, Mendeley, Zotero, Citeasy 등)에서 지원하는 범용 포맷입니다. 서지정보들을 RIS 파일 형태로 내보내기 할 수 있다는 것은, Sickle-Cite로 추출한 서지정보를 각종 서지관리 프로그램에서 가져오기(import) 할 수 있다는 것을 의미합니다.
		- 다만 Sickle-Cite는 논문의 서지정보를 영어로는 추출 및 저장하지 않으므로, 영문 제목 등 영어로 된 정보는 내보내기 하는 파일에 포함되지 않습니다.

### 탭 3. 설정

<p align="center"><img width="650" alt="Image" src="https://github.com/user-attachments/assets/7711d423-e905-4e55-b12c-f889d1ca9f69" /></p>

- [<img src="docs/icons/settings.svg" width="16" height="16" align="absmiddle" alt=""> 설정] 탭에서는 인용 양식에서 일부 사항을 설정할 수 있습니다. (‘인용 형식 세부 설정’) 이 밖에 내역 저장 방식, 백업, 테마 등 프로그램 자체에 관한 사항도 설정할 수 있습니다. (‘프로그램 설정’)
- [<img src="docs/icons/settings.svg" width="16" height="16" align="absmiddle" alt=""> 설정] 탭에서 선택한 옵션은 [<img src="docs/icons/current-page.svg" width="16" height="16" align="absmiddle" alt=""> 현재 페이지 서지정보] 탭에서의 〈<img src="docs/icons/citation.svg" width="16" height="16" align="absmiddle" alt=""> 인용 표기〉에뿐 아니라 다운로드되는 엑셀 파일에서의 ‘인용 표기’ 열에도 영향을 미칩니다.
- 설정 저장 버튼은 따로 없습니다. 설정을 변경하시면, 그 즉시 변경 사항이 저장되고 반영됩니다.

현재 버전에서 설정할 수 있는 사항은 다음과 같습니다.

#### 인용 형식 세부 설정

- **인용 형식 조합**: 아래 1~4의 세부 설정들의 조합에 원하는 이름을 붙여 저장해 두고, 필요할 때 골라서 바로 바꿔 적용할 수 있습니다. (최대 10개) 예컨대 투고할 학술지마다 요구하는 양식이 다르다면, 학술지별로 조합을 만들어 두고 골라 쓰면 됩니다.
	- 처음에는 기본 설정으로 된 ‘Sickle-Cite 기본’ 조합 하나가 있습니다. 조합은 적어도 1개는 있어야 하므로, 마지막 남은 조합은 삭제할 수 없습니다.
	- 조합을 고르면 그 조합의 설정이 곧바로 적용됩니다. [<img src="docs/icons/current-page.svg" width="16" height="16" align="absmiddle" alt=""> 현재 페이지 서지정보] 탭의 〈<img src="docs/icons/citation.svg" width="16" height="16" align="absmiddle" alt=""> 인용 표기〉 위에 있는 ‘인용 형식 조합’에서도 조합을 바로 바꿀 수 있습니다.
	- 조합을 고른 뒤 세부 설정을 바꾸면 인용 표기에는 곧바로 반영되지만, 조합 이름 옆에 ‘(변경됨)’이 표시될 뿐 조합 자체는 바뀌지 않습니다. 이때 드롭다운 메뉴 오른쪽에 나타나는 [변경 사항을 이 조합에 저장] 또는 [현재 형식을 새 조합으로 저장]을 눌러 저장할 수 있습니다. 바꾼 설정이 이미 있는 다른 조합과 똑같다면, 같은 조합이 이름만 달리 여럿 생기지 않도록 저장할 수 없습니다.
	- 선택된 조합은 [이름 변경], [조합 삭제]를 할 수 있습니다. 조합을 삭제해도 지금 적용된 설정은 그대로 유지됩니다. 어느 조합에도 저장되지 않은 설정이 사라질 상황에서는 먼저 확인을 받습니다.
	- 테마, 동일 논문 저장 방식 등 ‘프로그램 설정’은 조합에 포함되지 않습니다.

1. 제목과 부제목 사이를 구분하는 기호로 무엇을 쓸 것인지를 정할 수 있습니다. 옵션은 다음과 같이 세 가지입니다.
	- (1) 줄표(em dash)를 쓰되 앞뒤를 한 칸 띄우는 경우(‘ — ’), (2) 줄표(em dash)를 쓰되 앞뒤를 띄우지 않는 경우(‘—’), (3) 콜론을 쓰는 경우(‘: ’)
2. 권호수를 표기하는 방식으로 무엇을 쓸 것인지를 정할 수 있습니다.
	1. ‘권’, ‘호’ 따위의 단위를 쓰지 않고, 권수 및 호수를 숫자만 표기하되, 호수를 괄호 안에 넣어 표기하는 방법 — 예: 37(3)
		- ‘호’에 해당하는 숫자를 무조건 괄호에 넣는 식으로 작동하는 것은 아닙니다. 권/호의 구분이 따로 없을 경우(즉 권/호 중 하나만 있을 경우) 괄호 없이 숫자만 표기됩니다.
		- 숫자 ‘0’을 넣는 표기법은 지원하지 않습니다.
	2. ‘권’, ‘호’와 같은 단위를 쓰는 표기법 — 예: 제57권 제2호
		- ‘권(volume)’을 나타내는 단위로 무엇을 쓸 것인지, ‘호(issue)’를 나타내는 단위로 무엇을 쓸 것인지를 사용자가 직접 지정할 수 있습니다. 즉 ‘권’, ‘호’ 외의 다른 말을 지정할 수 있습니다.
		- 권/호의 구분이 따로 없을 경우에 어떤 단위를 사용할 것인지를 선택할 수 있습니다. (‘권/호 구분 없을 시 단위’ 항목, 기본값 ‘집’ — 예: 제214집)
		- ‘권’, ‘호’뿐 아니라 ‘집’과 같은 단위도 사용자 마음대로 설정 가능합니다.
		- 이 옵션을 선택할 경우, 접두사 ‘제’를 붙일지 여부를 선택할 수 있는 토글 스위치가 생깁니다. 권수 앞의 ‘제’와 호수 앞의 ‘제’를 각각 따로 설정할 수 있습니다. (붙이는 것, 즉 토글 스위치 on이 디폴트 설정입니다. 권/호의 구분이 따로 없을 경우에는 호수 쪽 설정을 따릅니다.)
	3. ‘Vol.’, ‘No.’과 같은 접두사(만)을 붙이는 표기법 — 예: Vol.75 No.3
		- 위의 2번 옵션과 마찬가지로, 다른 접두사를 사용자 마음대로 지정할 수 있으며, 권/호의 구분이 따로 없을 경우에 어떤 접두사를 사용할지도 지정할 수 있습니다.
		- 만일 ‘Vol. 75 No. 3’과 같이 마침표(.) 뒤의 한 칸을 띄는 표기법을 원할 경우, 각 입력창에서 공백 하나씩을 추가하면 됩니다.
3. 논문 제목, 학술지 제목을 나타내는 기호로 낫표 대신 화살괄호를 사용할 수 있습니다.
	- 토글 스위치를 on 하면 홑낫표(「 」) 대신 홑화살괄호(〈 〉)를 사용할 수 있습니다. (off가 디폴트입니다.)
	- 토글 스위치를 on 하면 전각 홑낫표(「 」) 대신 반각 홑낫표(｢ ｣)를 사용할 수 있습니다. (off가 디폴트입니다.) 다만 전각 홑낫표가 표준이므로, 반각 홑낫표 사용은 권장하지 않습니다. 홑화살괄호를 쓰도록 설정한 경우에는 이 토글 스위치가 비활성화됩니다.
	- 토글 스위치를 on 하면 겹낫표(『 』) 대신 겹화살괄호(《 》)를 사용할 수 있습니다. (off가 디폴트입니다.)
4. 논문 전체 쪽 범위를 인용 표기에 추가할지 여부를 설정할 수 있습니다. (추가하는 것, 즉 토글 스위치 on이 디폴트입니다. 쪽 정보가 없는 논문에서는 추가되지 않습니다.)
	- 쪽 범위를 추가할 경우, 쪽 범위 구분자를 무엇으로 할 것인지 설정할 수 있습니다. 디폴트는 en dash(–)이지만, 원한다면 예컨대 tilde(~)로 바꾸실 수 있습니다.
	- 또한 단위를 무엇으로 할 것인지 설정할 수 있습니다. 디폴트는 ‘쪽’이지만, 원한다면 예컨대 ‘면’으로 바꾸실 수 있습니다.

#### 프로그램 설정

1. 동일 논문의 서지정보 저장: 같은 논문의 서지정보를 다시 추출할 때 이를 내역에 어떻게 저장할지 고를 수 있습니다.
	- 매번의 추출 시도를 각각 내역에 저장합니다. (디폴트)
	- 첫 번째 추출만 저장하고, 이후의 추출은 내역에 추가하지 않습니다. 이 옵션을 고르면 [기존 중복 항목 삭제] 버튼이 나타나며, 이를 누르면 기존 내역에서 같은 논문으로 판별되는 항목 중 첫 번째로 추출된 항목만 남기고 나머지를 삭제합니다. (태그 추가를 비롯한 수정 사항은 이미 같은 논문의 모든 항목에 반영되어 있으므로 사라지지 않습니다.)
2. 서지정보 추출 내역 내보내기(백업) 및 가져오기
	- [내보내기]를 누르면 내역 전체를 JSON 파일로 다운로드합니다.
	- [가져오기]를 누르고 백업해 둔 JSON 파일을 고르면, 기존 내역에 합칠지(합치기) 기존 내역을 지우고 파일의 내역으로 바꿀지(전체 교체하기) 고를 수 있습니다. 이를 통해 내역을 특정 시점으로 되돌리거나, 다른 컴퓨터·브라우저로 옮길 수 있습니다.
3. 테마: 밝은 테마, 어두운 테마, 자동 중에서 고를 수 있습니다. ‘자동’은 컴퓨터(운영체제)의 밝은 모드·어두운 모드 설정을 따릅니다. (‘자동’이 디폴트입니다.)
4. 단축키: 현재 설정된 단축키를 확인할 수 있습니다. (아래 [(3) 기타: 단축키](#3-기타-단축키) 참고)

## (3) 기타: 단축키

- 단축키를 눌러 확장 프로그램을 실행(즉, 팝업 창 열기 = 현재 페이지에서 논문 서지정보를 추출)할 수 있습니다. 마우스로 확장 프로그램 아이콘을 클릭하는 것보다 키보드 단축키를 누르는 것을 선호하실 경우, 이 기능을 활용하시면 됩니다.
- 디폴트로 설정된 단축키는 Windows의 경우 Ctrl + Shift + K, macOS의 경우 Command + Shift + K 입니다.
- 단축키는 사용자가 원하는 대로 설정할 수 있습니다. 그 방법은 다음과 같습니다. 크롬의 우측 상단의 ⠇ 버튼을 누르고, 확장 프로그램 → 확장 프로그램 관리 → 단축키로 가신 뒤 본 확장 프로그램(Sickle-Cite) 섹션의 ‘확장 프로그램 활성화’ 항목에서 단축키를 바꿔 설정할 수 있습니다.

# 3. 작동 범위와 한계

**이 확장 프로그램은 웹의 온갖 페이지에서 다 작동하는 것은 아닙니다. 주요 학술 데이터베이스의 논문 검색 결과 페이지에서만 작동합니다.** 현재로서는 **학술지 논문** 및 **학위논문**의 서지정보만 추출해낼 수 있습니다. 단행본은 지원하지 않습니다. 인터넷 기사 등도 지원하지 않습니다. 학술지 논문과 학위논문 외의 문서는 추후 지원 대상에 추가될 예정 없습니다.<br>
학위논문의 서지정보 추출은 RISS, DBpia, 연세대학교 도서관 웹사이트에서의 검색 결과에 한해 지원합니다. 단, RISS와 달리 DBpia에서는 학과 정보는 나와 있지 않아 애초에 추출할 수 있는 정보가 더 적을 뿐 아니라, 학위논문 페이지들의 정보 중구난방으로 되어 있는 경우가 많아, 미처 예상치 못한 방식으로 정보가 추출 및 정리될 가능성이 있습니다. **되도록 학위논문 서지정보 추출은 RISS에서 하시기를 권합니다.**

현재 지원되는 학술 데이터베이스(논문 검색 및 열람 서비스) 목록은 다음과 같습니다.

- KCI
- KISS
- RISS
- DBpia
- eArticle
- 교보 스콜라
- KOAJ
- 연세대학교 도서관 웹사이트 (2.0.0 버전부터)
	- 소장자료 상세 페이지(`library.yonsei.ac.kr/search/detail/…`)와 학술논문 검색(EDS) 상세 페이지(`library.yonsei.ac.kr/eds/detail/…`)를 지원합니다. 학술논문 검색 상세 페이지는 도서관에 로그인한 상태에서만 열립니다.
	- **연세대학교 도서관 웹사이트에서의 추출은 권장하지 않습니다.** 도서관 웹사이트의 페이지에는 원래 학술 DB 페이지보다 서지정보가 불충분하거나 불규칙하게 등록되어 있는 경우가 많아(예: 키워드나 국문 초록이 없음, 학위논문의 석사/박사 구분이 없음, 끝 쪽이 없음 등) 추출 시 누락이 일어날 수 있습니다. 해당 논문이 위의 학술 DB에도 있다면, 되도록 그 페이지에서 추출하시기를 권합니다.
	- 학술논문 검색(EDS) 결과는 자료 제공처(DBpia, KISS, KCI 등)마다 학술지 정보의 표기 형식이 제각각입니다. 이를 최대한 학술지명·권수·호수·쪽 범위로 나누어 추출하지만, 예외적인 형식에서는 일부가 빠지거나 잘못 나뉠 수 있습니다. 원래 페이지에 없는 정보는 비워 둡니다.

대학 도서관을 통해 인증하여 위 학술 데이터베이스에 접속한 경우(즉 주소가 `www-dbpia-co-kr.proxy.○○.ac.kr`, `www.riss.kr.libproxy.○○.ac.kr`처럼 바뀐 경우)에도 서지정보를 추출할 수 있습니다.

(지원되는 학술 데이터베이스 목록은 더 늘어날 수 있습니다.)

경우에 따라 서지정보 추출이 완벽하게 되지 않는 경우가 있을 수 있습니다. 이는 개발자가 개발 당시에는 미처 고려하지 못했던 변수가 생겼기 때문입니다. 서지정보가 추출에서 문제가 있을 경우, 이를 제보해주시면 최대한 고쳐보겠습니다.

작동 원리를 자세하게 설명드릴 필요까진 없겠지만, 쉽게 말하면 이 프로그램은 각각의 학술 데이터베이스의 웹페이지 구조에 하나하나 맞춰놓은 알고리즘에 기반해 동작합니다. 그렇기에 학술 데이터베이스 운영자가 웹페이지의 구조를 바꿀 경우, 그 전까지 문제 없이 추출이 되다가도 어느 날 갑자기 오작동을 일으킬 수 있습니다. 이럴 경우에도 제보해주세요. 각 웹페이지의 변화에 맞추어 업데이트하겠습니다.

# 4. 나가며

본 확장 프로그램은 무료로 제공됩니다. 프로그램을 만든 사람은 전문 개발자가 아니라 이거 만들려고/만들면서 Javascript 공부한 평범한 박사과정생입니다. 그런 만큼, 의도대로 작동하지 않는 등 미흡한 점이 있더라도 너른 양해 부탁드립니다. 물론 오작동이나 버그 제보 자체는 환영합니다.

여러 미흡한 점이 있음에도 불구하고, 이 프로그램이 너무나 마음에 드셨고 또 무료로 쓰기에 미안하다 하시면… 저한테 커피 한 잔 사주시면 됩니다.
